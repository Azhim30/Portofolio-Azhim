3 Kompetensi Utama Bidang TKJ

Materi yang sudah saya pelajari dan praktikkan selama menempuh jurusan Teknik Komputer dan Jaringan, lengkap dengan dokumentasi praktik.

COMP_01 · NETWORKING

Mikrotik

Konfigurasi perangkat jaringan menggunakan RouterOS Mikrotik, mulai dari pengaturan dasar router hingga membangun jaringan wireless dan hotspot untuk kebutuhan akses internet bersama.

🖧

Konfigurasi VLAN

Membagi satu jaringan fisik menjadi beberapa segmen jaringan virtual (VLAN) agar lalu lintas data lebih tertata, aman, dan efisien antar divisi atau ruangan.

📶

Hotspot & WLAN

Membangun jaringan nirkabel (WLAN) lengkap dengan sistem login hotspot, termasuk pengaturan user profile, bandwidth limiter, dan halaman login kustom.

⚙️

Konfigurasi Dasar

Pengaturan awal router Mikrotik seperti reset konfigurasi, pemberian IP address, DHCP server, NAT, dan routing sederhana sebagai fondasi sebelum konfigurasi lanjutan.

COMP_02 · INFRASTRUCTURE

Fiber Optik

Praktik penyambungan kabel fiber optik menggunakan alat splicing, keterampilan penting untuk instalasi jaringan backbone berkecepatan tinggi.

🔬

Splicing

Menyambung dua ujung serat optik menggunakan fusion splicer agar cahaya dapat merambat tanpa hambatan berarti, lengkap dengan pengukuran redaman (loss) menggunakan OPM.

COMP_03 · SYSTEM ADMIN

Server

Instalasi dan pengelolaan sistem operasi server berbasis Linux sebagai dasar untuk menjalankan berbagai layanan jaringan.

🖥️

Instalasi OS Debian

Melakukan instalasi sistem operasi Debian Server dari awal, termasuk partisi disk, konfigurasi jaringan dasar, dan persiapan sistem sebelum instalasi layanan server.
